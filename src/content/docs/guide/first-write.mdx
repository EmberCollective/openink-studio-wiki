从一张空白 A4 纸开始，写下第一句“你好”。只调整这次用得到的设置，先感受一次完整的书写过程。

<div class="lesson-meta"><span>01 · 空白纸书写</span><span>准备：笔、写字机、A4 废纸</span></div>

## 01 / 选一张 A4 纸

1. 打开桌面应用。已有工程时，先保存，再从左上角 **文件 → 新建工程** 开始。
2. 点击最左侧的 **画板**，在 **版面设置** 中点击 **模板库**。
3. 选择 **A4 文档**。检查页面宽度 **210 mm**、高度 **297 mm**。

<Figure src="/openink-studio-wiki/images/a4-paper.svg" alt="A4 设置示意：画板、版面设置、模板库；核对 210 × 297 mm" label="操作示意" caption="选择 A4 文档后，核对页面宽度 210 mm、高度 297 mm。示意图不代表设备的实际可达范围。" />

**检查一下：** 中间出现竖向纸张，左侧尺寸为 210 × 297 mm。这个尺寸表示画布，不代表机器已经验证能走满整张 A4；第一次只在中间小范围试写。

## 02 / 放入你想写的话

1. 点击最左侧 **素材 → 输入文字**。
2. **字体来源** 选择 **普通字体 · TTF / OTF**，在 **书写字体** 中选一个能显示中文的字体；列表没有时，用旁边的文件按钮选择自己的字体文件。
3. 把文字框内容改为 **你好**，文字排版保留 **自由排版**，先用默认字号。
4. 点击 **插入文字到画布**，等画布出现笔迹。若只想先验证链路，可关闭 **提取字体中心线**；此时字会沿轮廓描边，属于正常现象。

<Figure src="/openink-studio-wiki/images/text-panel.jpg" alt="文字输入面板：选择普通字体、输入你好，然后插入文字到画布" label="界面参考 · 点击查看大图" caption="素材 → 输入文字。先选字体，再填写内容，最后点击“插入文字到画布”。图为浏览器预览，尚未选择字体或生成笔迹。" narrow />


在画布上框选笔迹即可移动和缩放。保留清楚可见的短文字即可，第一次不必调整整页样式。

:::tip[改字后要注意]
**插入文字到画布** 会新增素材。输错时先撤销刚才的插入，再改文字并重新插入，避免两份文字叠在一起。画布中已有的字迹可直接框选、移动或缩放。
:::

## 03 / 放好纸，连接设备

1. 用 USB 连接机器，点击右上角 **设备未连接** 打开连接区。扫描并选择这台机器的串口，点击 **连接设备**，等状态显示 **Idle**（空闲）。
2. 固定一张废纸，确认笔架能在计划区域内移动。先按设备要求手动归位，并完成笔高标定；不清楚笔高是否正确时，先不要开始任务。
3. 点击 **抬笔**，用 **0.1 mm 或 1 mm** 的小步长点动，核对按钮方向和实际方向一致。再把笔尖移到纸上准备起写的位置。

<Figure src="/openink-studio-wiki/images/device-panel.jpg" alt="设备连接面板：右上角打开连接区，在串口列表选择设备后连接" label="界面参考 · 点击查看大图" caption="右上角“设备未连接”打开连接区。图中未接设备，控制按钮暂不可用。" />

<Figure src="/openink-studio-wiki/images/jog-panel.jpg" alt="右侧手动控制与任务控制：移动步长、抬笔以及开始书写按钮" label="界面参考 · 点击查看大图" caption="小步长点动用于微调笔尖。截图中的 Z 值仅为示例，请按自己的设备标定笔高。" narrow />


这里使用新建工程的默认方式：任务区提示 **“开始先抬笔，从当前笔尖起写”**。它会把规划后的第一笔起点放在当前笔尖处，**不是按画布左上角在纸上定位**；第一次请在四周都有余量的区域试写。

:::caution[若看到“待校准”]
如果工程已有定位比例或保存的校准信息，可能要求重新校准。不要强行跳过；可保存后新建空白工程重做本课，或按[第二课的两点校准](../pdf-write/#04--对齐画布与纸面)完成定位。
:::

## 04 / 写出第一句话

1. 看一遍画布，确认只有要写的内容，笔尖和纸张位置也已检查。
2. 在右侧 **任务控制** 点击 **开始书写**，观察第一小段。
3. 需要暂停观察时点击 **暂停**；方向错误、撞边或笔高异常时点击 **停止**。停止后先核对纸面，不直接重发整份任务，以免重描。
4. 等软件提示完成，且机器**已抬笔、停稳并回到空闲状态**，再取纸。

<Figure src="/openink-studio-wiki/images/write-controls.svg" alt="任务控制入口示意：开始书写、暂停、停止；等待机器抬笔停稳才取纸" label="操作示意" caption="先试写少量内容。任务完成、笔已抬起、机器停稳后，再取下纸张。控制入口示意，非界面截图。" />

**写好了。** 纸上出现“你好”，机器抬笔停稳，就是这次的完成标志。 如果按钮不可点击，先看它下方的原因：未连接就连接设备；没有路径就先插入文字；超出范围就缩小内容并检查起笔位置。

用 **文件 → 保存** 把作品保存为 `.inkproj`。接下来试试[在 PDF 底稿上填写文字](../pdf-write/)。
